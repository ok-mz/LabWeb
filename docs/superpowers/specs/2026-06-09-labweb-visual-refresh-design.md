# LabWeb Visual Refresh Design

## Direction

Use the "modern research portal" direction: clean, professional, credible, and content-first. The site should feel like a polished university lab website rather than a generic admin template.

## Scope

- Refresh shared visual language through global CSS variables, banners, cards, buttons, spacing, and typography.
- Redesign the public navigation and footer with clear Chinese labels.
- Rework the homepage hero and content sections to create stronger hierarchy and a more refined first impression.
- Improve the public Agents page because it is one of the site's differentiating features.
- Lightly polish the admin shell so it feels consistent with the public site.
- Fix mojibake Chinese strings in the files touched during the refresh.

## Constraints

- Keep the existing Vue 3, Vite, Element Plus, Pinia, and API structure.
- Do not change backend behavior or database schema.
- Preserve current routes and data contracts.
- Avoid unrelated refactors.

## Visual System

- Palette: deep navy for authority, research blue as the primary action color, cyan/teal accents for life science and AI cues, and warm off-white surfaces to avoid a cold template look.
- Shape: 8px radius for cards and controls, with restrained shadows.
- Layout: wider breathing room on public pages, stronger section headings, and denser but organized admin UI.
- Chinese copy: clear, formal, and concise.
